# Why

Answer from the record, not the code: read the commits and PR discussions that introduced the target and each later change, and other sources if the trail is thin. Use only the tools this session actually exposes, and report a source it does not offer as an evidence gap. Cite what the authors wrote, mark your own inferences as inferences, and say what the record does not answer.
